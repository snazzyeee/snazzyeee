# Sudhanshu Pendalwar

I build market analytics tools, web applications, and video automation pipelines with Python and TypeScript. My work includes a custom canvas charting engine, tools for editing Hinglish gameplay videos, and gameplay systems in Godot and Roblox.

## Featured projects

**[Ramhos Charts](https://ramhos.com)**: Charting and options analytics for Indian markets · *private source*  
Built a custom canvas charting engine with synced multi-chart layouts, technical indicators, a live options chain, and multi-leg strategy analysis. Custom indicators run in bounded Web Workers. Integrates broker market data while keeping broker credentials encrypted in the user's browser, alongside accounts, saved workspaces, and subscription management.  
`TypeScript` · `Canvas` · `Web Workers` · `Python` · `FastAPI`

**[TEDxDYPDPU Attendance System](https://github.com/snazzyeee/tedx-attendance-system)**: Attendance management for an organising committee of roughly 70 people across six domains  
Uses Google Sheets as the shared record, with domain permissions and attendance windows enforced on the server. Batched writes keep API usage low; administrative overrides, an audit trail, and analytics support the committee's daily workflow. The public repository uses a placeholder roster.  
`Next.js` · `TypeScript` · `Google Sheets API` · `JWT`

**[Spider-Man 2000 Rebuilt](https://github.com/snazzyeee/spiderman-2000-rebuilt)**: Unofficial Godot reimplementation · *work in progress*  
Recreating traversal systems including web swinging, zip movement, and wall and ceiling crawling, with asset-conversion tooling and automated synthetic regression tests. The rooftop mission slice requires locally supplied original game assets; the public code and synthetic tests contain no game files.  
`Godot 4` · `GDScript` · `Python` · `CI`

**PNDLWR Engine**: Local video editing and captioned Shorts · *private source*  
Builds Shorts from longer videos with speech recognition, clip selection, caption review, and FFmpeg rendering. Preserves spoken Hindi as Roman Hinglish rather than translating it into English. Also supports whole-match gameplay edits, with an AI video workflow in development.  
`Python` · `Whisper` · `Gemini` · `FFmpeg`
